# STM32 Dual-Channel ADC to PWM & OLED Monitor

Проект на базе микроконтроллера **STM32F103**, считывающий аналоговые сигналы с двух каналов АЦП в режиме DMA, управляющий скважностью двух каналов ШИМ и выводящий текущее напряжение на OLED-дисплей SSD1306.

## Основные возможности
* **АЦП (ADC1 + DMA):** Непрерывное сканирование 2 каналов (PA1, PA2) с разрешением 12 бит.
* **ШИМ (TIM3):** Генерация двух независимых ШИМ-сигналов (PA6, PA7) с управлением скважностью от АЦП.
* **Дисплей (I2C2):** Вывод напряжения (в Вольтах) на OLED SSD1306 (PB10, PB11).
